  Design Document Highlights

  Core Technique: Mip-Map Gaussian Approximation

  - 5-pass pipeline: Bright Pass → Mip Generation → Blur → Upsample →
  Composite
  - Performance target: < 2ms at 1080p
  - Quality: Smooth, natural bloom using ~6-8 texture samples (vs 100+ for
  traditional Gaussian)

  Key Technical Features

  1. HDR Color Pipeline
    - RGB16F texture format throughout
    - Proper luminance-based threshold extraction
    - ACES filmic tone mapping in final composite
    - Handles values > 1.0 correctly
  2. Optimization Strategies
    - Half-resolution rendering (960×540 for 1080p input)
    - Hardware mip-map generation leveraged
    - Optional tent filter for upsampling
    - Configurable quality presets (Low/Medium/High)
  3. SGCT Integration
    - New BloomEffect class encapsulates all bloom logic
    - Clean integration into simplecube/main.cpp
    - Keyboard controls: B (toggle), ↑/↓ (adjust strength)
    - Works with existing postProcess() callback

  Pass Breakdown

  Pass 1: Bright Pass (0.1ms) - Extract luminance > threshold at half-res
  Pass 2: Mip Gen (0.2ms)     - Generate 6 mip levels via glGenerateMipmap
  Pass 3: Blur (0.2ms)        - Sample 6 mip levels with Gaussian weights
  Pass 4: Upsample (0.3ms)    - Reconstruct full-res with tent filter
  Pass 5: Composite (0.2ms)   - Blend + ACES tone map + gamma correct
  ────────────────────────────────────────────────────────────
  Total: ~1.0ms @ 1080p
